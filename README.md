# Go Hands-On Projects

A collection of hands-on projects built while learning Go through practical software engineering exercises.

The goal of this repository is to learn Go by building small, focused projects that gradually introduce core language features, backend development concepts, testing practices, concurrency patterns, and production-ready engineering techniques.

---

## Repository Structure

Each project is self-contained and includes:

- Source code
- Unit tests
- Project-specific documentation
- Setup and execution instructions

```text
go-hands-on-projects/
├── 01-hello-universe/
├── 02-...
├── 03-...
└── README.md
```

## Why This Repository?

Rather than following isolated tutorials, this repository documents my journey of learning Go by building projects incrementally and applying software engineering principles to real-world-style problems.

Each project focuses on a specific set of concepts while reinforcing best practices around code organization, testing, and maintainability.
